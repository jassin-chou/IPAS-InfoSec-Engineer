# IPAS InfoSec Engineer

**守盾群島 Shield Isles** — iPAS 資訊安全工程師（初級）3D 互動答題城市
A 3D interactive quiz city for the iPAS Information Security Engineer (Associate) exam.

由 21 座六角小島組成的玩具風格城市，把兩個考科的 20 個主題變成可以走逛的島嶼。點選島嶼，分身「小盾」就會走過去，即時答題並公布答案與解析。
A toy-style city of 21 hexagonal islands, where each island covers one of the 20 exam topics across both subjects. Click an island and your avatar walks there, so you can answer questions and see the correct answer and explanation right away.

## 特色 Features
- 300 題，依科目與章節分類 · 300 questions, grouped by subject and chapter
- 20 座島、89 課互動教學（OSI 封裝動畫、SQL Injection 實驗室、備份還原模擬器等）· 89 interactive lessons across 20 islands (OSI encapsulation animation, SQL injection lab, backup restore simulator and more)
- 即時解析、錯題重練、收藏 · Instant explanations, wrong-answer review, bookmarks
- 模擬考與島嶼熟練度旗幟 · Mock exams and a mastery flag on every island
- 釣魚小遊戲：每條魚帶來一個觀念和一道題 · Fishing mini-game: every fish brings one concept and one question
- 原創配樂、日夜模式 · Original background music, day and night modes

## 使用 Usage
用瀏覽器開啟 `index.html`（需連網載入 Three.js）。
Open `index.html` in a browser (needs an internet connection to load Three.js).

線上版 Live: https://jassin-chou.github.io/IPAS-InfoSec-Engineer/
